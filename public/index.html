Government Affairs — Policy Note proxy

Netlify functions keep the PolicyNote API key off the public Sitefinity site.

  • GET /api/policy-note/health
  • GET /api/policy-note/lookup?bill=H.R.%20906 (header x-ga-policy-key when configured)
  • /ga-policy-map.js — map client for Issue detail pages
  • /ga-layout-hotfix.js — runtime list/detail layout override when old Sitefinity templates are still live
